# Folder Aset Animated SVG

Taruh file asset animated SVG Anda di dalam folder ini:
`public/animations/`

File yang ditaruh di sini dapat diakses langsung dari aplikasi Next.js melalui path:
`/animations/[nama-file-svg-anda].svg`

Contoh penggunaan:
- `<Image src="/animations/my-animated-icon.svg" alt="Animated Icon" width={100} height={100} />`
- atau `<img src="/animations/my-animated-icon.svg" alt="Animated Icon" className="w-24 h-24" />`
- atau di-*import* langsung ke dalam komponen JSX.
